# 🎯 ArbiChief - Настольное приложение Windows

**ArbiChief** - менеджер турниров, теперь доступный как настольное приложение для Windows!

---

## 📥 Быстрая установка

### Вариант 1: ZIP архив (рекомендуется)
1. Скачайте `ArbiChief-1.0.0-win.zip`
2. Распакуйте архив в любую папку
3. Запустите `ArbiChief.exe`

### Вариант 2: Портативная версия
1. Скачайте папку `ArbiChief-Portable/`
2. Скопируйте куда угодно (USB, папка, рабочий стол)
3. Откройте папку и запустите `ArbiChief.exe`

---

## ✨ Возможности

- 🏆 **Управление турнирами** - создание и настройка турниров
- 👥 **Команды и игроки** - управление участниками
- 🎲 **Генерация пар** - автоматическое создание пар для матчей
- 📊 **Подсчёт рейтингов** - система подсчёта очков и таблица результатов
- 📅 **Календарь** - расписание турниров
- 🔔 **Напоминания** - уведомления о предстоящих событиях
- 📤 **Экспорт/Импорт** - сохранение и загрузка данных

## 🚀 Для разработчиков

### Запуск в режиме разработки

```bash
# Установка зависимостей
npm install

# Запуск веб-версии
npm run dev

# Запуск Electron-версии с hot-reload
npm run electron:dev
```

### Сборка приложения

```bash
# Быстрая сборка
npm run electron:build:win

# Или используйте автоматический скрипт
powershell -ExecutionPolicy Bypass -File .\build-electron.ps1
```

Результат сборки будет в папке `release/`:
- `ArbiChief-1.0.0-win.zip` - ZIP архив
- `win-unpacked/` - Распакованная версия
- `ArbiChief-Portable/` - Портативная версия

## 🔧 Устранение проблем

### Антивирус блокирует?
Это нормально для неподписанных приложений. Добавьте папку в исключения или дождитесь проверки.

### Приложение не запускается?
1. Убедитесь, что у вас Windows 10/11 (64-bit)
2. Попробуйте запустить от имени администратора
3. Проверьте, не заблокирован ли файл (ПКМ → Свойства → Разблокировать)

### Ошибка при сборке?
```bash
# Очистка и пересборка
Remove-Item -Path ".\node_modules" -Recurse -Force
npm install
npm run electron:build:win
```
