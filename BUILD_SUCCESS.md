## 📤 Как распространять приложение:

### Для конечных пользователей:
Отправьте один из файлов:
- `ArbiChief-1.0.0-win.zip` - компактный архив
- `ArbiChief-Portable/` - папка с README

### Инструкция для пользователей:
1. Распакуйте ZIP архив (если получили ZIP)
2. Откройте папку
3. Дважды кликните на `ArbiChief.exe`
4. Готово! Приложение запустится

## ⚠️ Важные замечания:

### Почему нет установщика?
Из-за ограничений прав доступа Windows для создания символических ссылок, 
установщик NSIS требует дополнительных настроек подписывания кода. 

**Решение:** Используйте портативную версию или ZIP архив.

### Антивирус может блокировать
При первом запуске Windows Defender может проверить файл. Это нормально для неподписанных приложений.
- Дождитесь завершения проверки
- Или добавьте папку в исключения антивируса

### Требования к системе:
- ✅ Windows 10 или выше (64-bit)
- ✅ 4 ГБ RAM (рекомендуется)
- ✅ 500 МБ свободного места

## 🔧 Повторная сборка:

Если нужно пересобрать приложение:

```bash
# Очистка предыдущей сборки
Remove-Item -Path ".\release" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item -Path ".\dist" -Recurse -Force -ErrorAction SilentlyContinue

# Новая сборка
npm run electron:build:win

# Создание портативной версии
Copy-Item ".\release\win-unpacked" ".\release\ArbiChief-Portable" -Recurse -Force
```
