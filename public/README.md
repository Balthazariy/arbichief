# Иконка для ArbiChief

Поместите файл `icon.ico` в эту папку для использования в качестве иконки приложения.

Требования к иконке:
- Формат: .ico
- Рекомендуемый размер: 256x256 пикселей
- Поддержка нескольких разрешений (16x16, 32x32, 48x48, 128x128, 256x256)

Вы можете создать .ico файл из изображения PNG/JPG с помощью онлайн-конвертеров:
- https://www.icoconverter.com/
- https://convertio.co/ru/png-ico/
